CHANGES IN THIS CLEANUP
=======================
- Removed all emoji icons for a professional look
- Straightened table columns and action buttons into consistent grids
- Uniform button heights and alignment
- Removed scanlines, neon glow excess, and external Google Fonts
- System font stack for speed and a lighter footprint
- Clean dark + light themes (theme toggle preserved)
- All sales pipeline features kept: statuses, money, follow-ups, live sites, dashboard

FEATURES
========
1. SALES PIPELINE STATUSES
   NOT CALLED > CALLED > AGREED > BUILDING > WEBSITE LIVE

2. WEBSITE LINK FOR BUILT SITES
   Live Sites tab lists delivered websites with Open / Copy / WhatsApp

3. MONEY TRACKING
   Quote price (R) and Paid (R) per contact; dashboard totals

4. FOLLOW-UPS
   Set a follow-up date in Edit; Follow-ups tab lists due items

5. DASHBOARD
   Stat cards, pipeline donut, calls-per-day bars, top places, activity feeds
   Charts are pure SVG/CSS — no libraries, works offline

6. IMPORT / EXPORT
   CSV, VCF, JSON backup/restore; bulk paste; duplicate removal

STORAGE
=======
Data is stored in a Supabase Postgres table ("contacts") and syncs across
any device that opens this page. Requires an internet connection. See
SETUP.md for the table-creation step and a security note about the anon key.
